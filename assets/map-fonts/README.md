These are the complete 256 BMP SDF glyph pages for **Klokantech Noto Sans
Regular**, distributed by OpenMapTiles. The stack includes Noto Naskh Arabic
and Arabic presentation forms, alongside Latin and other scripts. MapLibre
Native performs Arabic shaping; no network font service is used.

The upstream archive and commit, SHA-256, each page's digest and license source
are recorded in `manifest.json`. The original SIL Open Font License 1.1 is in
`LICENSE-OFL.txt`. Copyright belongs to Google Inc. and Noto contributors;
glyph packaging is by Klokan Technologies / OpenMapTiles. These glyphs are
bundled with PalMesh under that license and are not sold separately.

Run `python3 scripts/maps/package.py --fonts-only` to verify every page and copy
the resources and license into Android and iOS assets. Full map packaging also
performs this step. Source and packaged copies deliberately have identical
bytes and fontstack names.
